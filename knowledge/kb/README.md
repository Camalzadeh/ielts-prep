# IELTS knowledge base: start here

These pages are curated from our teacher's IELTS course (Telegram group, 20 Jul – 13 Sep 2026)
and her **LATEST_EXAMS** channel (Jun–Oct 2026). Templates, sentence frames and model essays are
quoted from her handouts. Where a page adds general IELTS guidance, it says so.

**Suggested order:** [Exam format](exam-format-and-scoring.md) → [Band descriptors](band-descriptors.md) →
Task 2 overview and one essay type per day → Task 1 overview and one chart type per day → speaking
model answers every day → listening/reading tests from the [course timeline](course-timeline-and-resources.md).
